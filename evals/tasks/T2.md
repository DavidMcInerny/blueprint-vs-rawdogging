Base: pre-created app (working directory is the app root).

## Prompt

Add a saved-items feature to this app, reachable at route `/saved`:

- Storage: use `@react-native-async-storage/async-storage` (install it if the
  app does not already have it) under the key `eval.savedItems.v1`, storing a
  JSON array of item title strings. All storage access for this feature goes
  through one module.
- UI contract: a text input with testID `saved-title-input`, an add button
  with testID `saved-add-button`, and one row per saved item with testID
  `saved-item` whose text is the item title.
- Data survives reload: items added before a reload are still listed after it.
- Failed save: if writing to storage throws, keep the typed draft in the
  input, do not add the item to the list, and show an error element with
  testID `saved-error`.
- Corrupt storage: if the stored value is not valid JSON of the expected
  shape, do not crash and do not overwrite the stored value; show a notice
  with testID `saved-corrupt-notice` and render an empty list.

The app must pass `npx tsc --noEmit`.
