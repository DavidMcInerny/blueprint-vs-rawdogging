Base: pre-created app (working directory is the app root).
Fixture: `supplied/items.json` — an array of `{ "title": string,
"category": string }`.

## Prompt

Build a searchable, filterable list at route `/items` from the supplied data:

- Bundle `supplied/items.json` with the app (no network fetch): the list
  works fully offline.
- UI contract: a search input with testID `item-search`; one filter control
  per category with testID `item-category-<category>` plus `item-category-all`;
  one row per visible item with testID `item-row` showing its title; when no
  item matches, an empty-state element with testID `item-empty`.
- Search matches titles case-insensitively; search and category filter
  combine.
- Accessibility: the search input and filter controls must be reachable and
  operable by keyboard on web; the screen must have no axe violations; it
  must render correctly with reduced motion enabled at the OS level (do not
  gate content visibility on animation).
- The app must pass `npx tsc --noEmit`.
