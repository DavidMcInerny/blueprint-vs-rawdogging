## Prompt

Build a small persisted setting behind the supplied storage port:

1. Copy the supplied files into the app's source tree unchanged:
   `port.ts` defines `KeyValuePort { get(key): Promise<string|null>;
   set(key, value): Promise<void>; kind: string }`.
2. Implement a settings module that depends only on `KeyValuePort` and
   persists a display name under the key `eval.displayName`.
3. Add a route `/adapter-demo` with: an input with testID
   `adapter-name-input`, a save button with testID `adapter-save-button`, a
   text element with testID `adapter-saved-name` showing the saved name, and
   a text element with testID `adapter-kind` showing the active port's
   `kind`.
4. Wire the app's composition root (the file that constructs the port) to use
   the supplied **memory** adapter. The adapter choice must be changeable by
   editing only that one composition file: no other file may import either
   adapter implementation or `@react-native-async-storage/async-storage`
   directly (the supplied async-storage adapter file itself excepted).

The app must pass `npx tsc --noEmit`.
